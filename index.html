📺 TV Addons - Dépôt Kodi

Serveur de dépôt local pour tester et distribuer les addons TV monorepo.

📥 Télécharger repository.tv-addons.zip

🚀 Installation dans Kodi

  1. Dans Kodi : Paramètres → Extensions → Installer depuis un fichier zip
  2. Sélectionnez repository.tv-addons.zip (ou ajoutez https://raw.githubusercontent.com/zibaone/tv-addons-repo/main comme source de fichiers).
  3. Une fois le dépôt installé, les addons et leurs mises à jour s'installeront automatiquement !
